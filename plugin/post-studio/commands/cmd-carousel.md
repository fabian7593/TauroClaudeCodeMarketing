---
description: Generar un post de carrusel (varias imágenes, un solo texto) a partir de una colección de imágenes
---

Generá un post de carrusel usando la colección de imágenes en `<contentRoot>/assets/posters/$ARGUMENTS/` (`<contentRoot>` sale de `brand.config.json`, default `POST/`).

Usá el skill `post-carousel`. Si `$ARGUMENTS` está vacío, o esa carpeta no existe o está vacía, preguntame el nombre de la colección (subcarpeta dentro de `assets/posters/`) antes de continuar — no busques imágenes sueltas en otro lado para armarla.
